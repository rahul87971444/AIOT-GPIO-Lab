# AIOT-GPIO-Lab
# AIOT GPIO Lab Experiments – Raspberry Pi

This repository contains Python programs developed as part of the
AIOT Laboratory Assignment using Raspberry Pi GPIO pins.

The experiments demonstrate digital input/output control, PWM-based
LED dimming, push button interfacing, and binary counter implementation
using both gpiozero and RPi.GPIO libraries.


## Hardware Used
- Raspberry Pi 4 Model B
- LEDs
- 330Ω Resistors
- Push Buttons
- Breadboard
- Jumper Wires

---

## Concepts Covered
- GPIO Digital Input and Output
- PWM (Pulse Width Modulation)
- Push Button Interfacing
- LED Dimming
- Exception Handling
- Binary Counting using GPIO

---

## Conclusion
All GPIO experiments were successfully implemented and verified.
